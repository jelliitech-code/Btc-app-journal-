3. DATA STRUCTURES & ALGORITHMS (DSA) SPECIFICATION
--------------------------------------------------------------------------------
The terminal implements four core computer science data structures directly in
JavaScript for real-time quantitative processing:

1. Fenwick Tree (Binary Indexed Tree — `FenwickTree` class)
   - Time Complexity: O(log N) point update, O(log N) prefix sum & range sum.
   - Space Complexity: O(N) typed Float64Array (N = 48 price bins).
   - Application: Computes the 48-bin Volume Profile, Point of Control (POC),
     and expands the 70% Value Area (VAH / VAL) via binary range queries
     `bit.rangeQuery(leftBin, rightBin)` without O(N^2) array rescanning.

2. Binary Max-Heap Priority Queue (`MaxHeap` class)
   - Time Complexity: O(log K) insertion (`push`), O(log K) extraction (`pop`).
   - Application:
     (a) Ranks all 6 timeframe trade blueprints in real time by composite
         mathematical Expected Value: Score = 100 * EV_R + 50 * P(tau_TP1 < tau_SL).
     (b) Extracts the top 8 Iceberg Absorption price buckets ranked by
         RefillScore = (V_executed / V_visible) * V_executed.
     (c) Extracts the top 10 institutional Whale Prints (> 0.85 BTC single clips).

3. Monotonic Double-Ended Queue (`MonotonicDeque` class)
   - Time Complexity: O(1) amortized insertion and sliding-window min/max query.
   - Application: Tracks rolling structural highs/lows and stop-sweep extremes.

4. Circular Ring Buffer (`RingBuffer` class)
   - Time Complexity: O(1) overwrite-oldest insertion with zero garbage-
     collection allocation overhead.
   - Application: Maintains the trailing 1,000 aggressive market trade prints
     for real-time VPIN toxicity bucketing and whale tape inspection.


4. COMPLETE WALL STREET FINANCIAL MATHEMATICS & CLOSED-FORM EQUATIONS
--------------------------------------------------------------------------------

A. 1D KINEMATIC STATE-SPACE KALMAN FILTER (PRICE & VELOCITY ESTIMATION)
   State Vector at bar k:
     x_k = [ p_k, v_k ]^T   (where p_k = latent price, v_k = price velocity)

   State Transition Matrix (F) & Observation Matrix (H):
     F = [ [1, 1], [0, 0.96] ],   H = [1, 0]

   Prediction Step:
     x_{k|k-1} = F * x_{k-1|k-1}
     P_{k|k-1} = F * P_{k-1|k-1} * F^T + Q_k
     where process noise Q_k = diag((0.08 * ATR_k)^2, (0.03 * ATR_k)^2)

   Measurement Update Step (Adaptive Volatility Scaling):
     Innovation Residual:   y_k = z_k - H * x_{k|k-1}   (z_k = observed Close)
     Innovation Covariance: S_k = H * P_{k|k-1} * H^T + R_k
     where measurement noise R_k = (0.48 * ATR_k)^2
     Kalman Gain:           K_k = P_{k|k-1} * H^T * S_k^{-1}
     Posterior State:       x_{k|k} = x_{k|k-1} + K_k * y_k
     Posterior Covariance:  P_{k|k} = (I - K_k * H) * P_{k|k-1}


B. HURST EXPONENT (RESCALED RANGE R/S PERSISTENCE ANALYSIS)
   Given log returns r_1, r_2, ..., r_N partitioned into sub-windows of scale n:
     Mean:                  m = (1/n) * sum_{i=1}^n r_i
     Cumulative Deviation:  Y_t = sum_{i=1}^t (r_i - m)
     Range:                 R(n) = max_{1<=t<=n}(Y_t) - min_{1<=t<=n}(Y_t)
     Standard Deviation:    S(n) = sqrt( (1/n) * sum_{i=1}^n (r_i - m)^2 )
     Scaling Law:           E[ R(n) / S(n) ] = C * n^H
   Estimated via Ordinary Least Squares (OLS) slope of log(R/S) vs log(n) for
   n in {8, 16, 32, 64}:
     - H > 0.55 : Persistent Trend-Following Regime (positive memory)
     - H = 0.50 : Geometric Brownian Motion / Random Walk
     - H < 0.45 : Anti-Persistent Mean-Reverting Regime


C. ORNSTEIN-UHLENBECK (OU) STOCHASTIC DIFFERENTIAL EQUATION
   Continuous-time mean-reverting SDE:
     dX_t = theta * (mu - X_t) dt + sigma_OU dW_t

   Discrete AR(1) calibration on closes:
     X_t - X_{t-1} = a + b * X_{t-1} + epsilon_t
     Mean-Reversion Speed:  theta = -ln(1 + b)
     Long-Run Equilibrium:  mu = -a / b
     Mean-Reversion Half-Life (50% decay time):
                            tau_{1/2} = ln(2) / theta
     Equilibrium Z-Score:   Z_OU = (X_t - mu) / (sigma_epsilon / sqrt(2 * theta))


D. YANG-ZHANG DRIFT-INDEPENDENT REALIZED VOLATILITY (sigma_YZ)
   Minimum-variance unbiased estimator combining overnight jumps and intraday
   Rogers-Satchell volatility over window n:
     sigma_O^2  = Var( ln(Open_t / Close_{t-1}) )
     sigma_C^2  = Var( ln(Close_t / Open_t) )
     sigma_RS^2 = (1/n) * sum [ ln(H_t/C_t)*ln(H_t/O_t) + ln(L_t/C_t)*ln(L_t/O_t) ]
     k          = 0.34 / (1.34 + (n + 1)/(n - 1))
     sigma_YZ   = sqrt( sigma_O^2 + k * sigma_C^2 + (1 - k) * sigma_RS^2 )


E. GARCH(1,1) CONDITIONAL VOLATILITY FORECAST
   Autoregressive conditional heteroskedasticity variance recursion:
     sigma_t^2 = omega + alpha * r_{t-1}^2 + beta * sigma_{t-1}^2
     with institutional crypto parameters omega = 10^{-6}, alpha = 0.14,
     beta = 0.82 (alpha + beta = 0.96 < 1 for stationarity).
     h-bar Forecast Cone:
       68% Interval = Forecast_h +/- 1.00 * sigma_t * sqrt(h)
       95% Interval = Forecast_h +/- 1.96 * sigma_t * sqrt(h)


F. FIRST-PASSAGE BARRIER CROSSING PROBABILITY (DRIFT-DIFFUSION PDE)
   Given entry price E, distance to Take-Profit B = |TP - E|, distance to
   Stop-Loss A = |E - SL|, Kalman drift per bar mu_d, and volatility sigma:
     Peclet Parameter:      lambda_p = (2 * mu_d) / sigma^2
     Exact Analytical Hitting Probability P(tau_TP < tau_SL):
       If |lambda_p| -> 0:
         P(Hit TP before SL) = A / (A + B)
       If |lambda_p| > 0:
         P(Hit TP before SL) = (1 - exp(-lambda_p * A)) / (exp(lambda_p * B) - exp(-lambda_p * A))

   Expected Median First-Passage Touch Time (Inverse Gaussian Law):
     n_{50%} = ( Distance / (0.6745 * sigma) )^2  bars


G. VPIN (VOLUME-SYNCHRONIZED PROBABILITY OF INFORMED TRADING) & KYLE'S LAMBDA
   Volume-bucketed order flow toxicity across M equal-volume buckets of size V_b:
     VPIN = (1 / (M * V_b)) * sum_{tau=1}^M | V_tau^{Buy} - V_tau^{Sell} |

   Kyle's Lambda Market Impact Coefficient:
     Delta P_t = lambda * OFI_t + epsilon_t
     lambda = Cov(Delta P, OFI) / Var(OFI)   (in USD per 1 BTC net order flow)

   Iceberg Absorption Refill Ratio at Price Bucket p:
     I_p = V_{executed}(p) / max(0.25, V_{visible}(p))


H. CONTINUOUS KELLY CRITERION & GEOMETRIC WEALTH COMPOUNDING

   and net reward-to-risk payoff ratio b = R_win / R_loss:

     Quarter-Kelly Safe Size:  f_{0.25} = 0.25 * f*
